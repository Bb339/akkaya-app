# Geographic scope contract

Verified institutional water evidence requires an explicit scope on all six types: annual supply, monthly supply, delivery, environmental release, conveyance efficiency, and perennial requirement. Missing scope and wrong district scope block execution. `project` is valid only when explicit; a district is valid when it exactly matches the requested pilot scope. Data stored for another project is never selected by this project store.

Historical/reference records may remain readable without retroactive migration, but they cannot become eligible verified institutional evidence through a silent `project` default.
