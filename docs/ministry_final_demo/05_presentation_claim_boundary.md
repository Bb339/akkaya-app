# Presentation Claim Boundary

## Safe to say now

- The software supports project-scoped verified institutional datasets.
- Datasets are versioned and become active only after explicit confirmation.
- Readiness is fail-closed.
- Analyses are pinned to input versions and selection hashes.
- Run and input provenance is retained.
- The Reference Demo is reproducible under frozen reference inputs.
- The accepted synthetic institutional end-to-end workflow demonstrates the software path.
- Full-project S1 robustness evidence exists under frozen 2024 inputs.

## Do not say

- Ministry data have already been integrated.
- Recommendations are officially approved.
- Outputs are field validated.
- Water allocation is official.
- Profit is verified farm income.
- Market feasibility is proven.
- Multi-year resilience is proven.
- External agronomic validity is proven.

All screenshots are demonstration evidence. Any later manuscript use requires the same visible reference/synthetic warnings and a claim boundary review.
