# Claim boundary

Evidence supports that one decision UI can use either frozen reference data or confirmed project-scoped data; supported structured schemas are deterministically inspected and versioned; malformed/low-confidence input fails closed; geometry is optional and isolated from optimization; project runs are pinned to revisions and configuration; and stored runs preserve provenance.

The milestone does not establish Ministry approval, field validation, universal document/schema understanding, scientific truth of uploaded values, market feasibility, predictive multi-year validity, soil validation, remote-sensing validation or production readiness. Synthetic results remain labelled **SYNTHETIC TEST DATA / NOT OFFICIAL**.
