# Article evidence summary

The evidence package demonstrates data-source generalization at the software-contract level: the frozen Akkaya provider and an independently uploaded 20-file project provider feed the same V1 workspace. It records 20/20 deterministic mappings, 24 project units, optional/partial geometry, readiness, pinned execution, stored results, project identity and provenance.

Adversarial cases cover Turkish aliases, BOM/semicolon CSV, reordered/extra columns, grouped numeric representations, partial numeric contamination, cover/empty/multiple Excel sheets, missing columns, wrong year, unsupported input and invalid GeoJSON. Counts are reported as test cases, not as a generalized accuracy percentage.

Suggested screenshots are the provider strip, bulk import mapping, readiness matrix, project selector/map, run configuration, stored summary, monthly water, crop composition, unit results and provenance. Every synthetic screenshot must retain its warning.
