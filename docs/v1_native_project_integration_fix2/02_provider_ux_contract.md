# Provider UX contract

Frozen index.html remains unchanged. Flask response adaptation adds a compact Veri Kaynağı control beside the existing session controls. It reports AKKAYA REF or PROJECT DATA.

The control opens a fixed right-side drawer outside normal document flow. It contains provider switching, exact project selection, project identity, year, revision, authority, classification, counts, area, crops, candidate and geometry coverage, backend readiness, preview state, requirements, project management and run history. Escape, close and backdrop actions close it. Mobile width is 100vw.

/projects remains the ingestion and data-management workspace. Karar Sisteminde Aç routes to the same V1 surface with provider=PROJECT_DATA and exact project_id.
