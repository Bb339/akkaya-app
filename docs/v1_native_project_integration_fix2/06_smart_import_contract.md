# Smart Import contract

IGNORED_NOT_RELEVANT applies only to a supported, parseable file with zero required-field matches and no filename or sheet hint for any supported domain. It creates no batch and cannot mutate the project. It does not block confirmation when a package has valid AUTO_MATCHED data.

Partial evidence, ambiguous mapping, type or sheet, malformed values, wrong year or scope, unsupported extension, invalid GeoJSON, duplicates and active-unit identity conflicts remain fail-closed.

Geometry unknown_unit may be deferred only for a bulk package staged at revision 0, before same-package analysis units are active. It is revalidated after analysis-unit confirmation. At nonzero revision the mismatch is definitive.
