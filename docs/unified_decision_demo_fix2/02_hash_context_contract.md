# Authoritative project hash contract

The project workspace hash is authoritative navigation state. Exactly one non-empty, validly encoded project parameter that exactly matches an existing project opens context. Missing fragments, bare hash, empty values, unrelated parameters, malformed encoding, duplicate project parameters, and unknown identities clear projectId, active cards, detail, result, preview, and stale-preview presentation and show an explicit error. No project or Akkaya/reference fallback is selected.

Card selection and project creation write the canonical project hash form. Hash changes deterministically support valid-to-valid, valid-to-invalid, and invalid-to-valid recovery.
