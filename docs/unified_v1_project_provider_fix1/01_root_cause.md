# Fix1 root cause

The stored run already contained separate optimizer and authoritative water values, annual-budget validation and warnings. The V1 project-provider adapter collapsed water into one generic card and did not render the annual object or warning arrays. Missing current metrics used an em dash without explaining the semantic state.

Smart Import preserved detector codes and failed closed, but its primary bulk-row explanation was a generic Turkish sentence. Case-specific English detector messages were available only in a title or raw JSON.

Fix1 changes presentation adapters, focused tests and evidence only. It does not change scientific calculations, readiness rules, data, reference behavior or deployment configuration.
