# Referans Demo arayüzü

Referans ekranı kurumsal veri girişi olmadan model gösterimi, eğitim ve ekran görüntüsü için korunur. “REFERENCE MODEL / DEMO DATA” ve “RESMÎ SU TAHSİSİ VEYA SAHA DOĞRULAMASI DEĞİLDİR” metinleri kaldırılmaz.

Dondurulmuş görünür değerler: 179 analiz birimi, 134.919 da, 6.859 aday satırı, 58 ürün, 100.700.080,81 m³ hesaplanmış referans su ve 1.041.499.119,212 TL katalog türevi referans kâr. Ana V1 deneyimine doğrudan bağlantı vardır. Bu ekran verified kurumsal kanıt gibi etiketlenmez.
