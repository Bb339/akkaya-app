# Çalıştırma profili UI sözleşmesi

`REFERENCE_DEMO` ve `VERIFIED_INSTITUTIONAL` bağımsız kimliklerdir. Seçim formu bunları backend kimlikleriyle gönderir; Türkçe açıklama yalnız sunum katmanıdır. Üst rozet, uyarı bandı, sonuç otoritesi ve ekonomi etiketi profili metinle tekrarlar.

Reference modunda “REFERENCE MODEL / DEMO DATA” ve resmî tahsis/saha doğrulaması olmadığı uyarısı görünür. Verified modunda çalıştırma ancak aynı veri revizyonu ve yapılandırma için başarılı önizleme kanıtı bulunduğunda açılır. Proje seçimi profili değiştirmez. Sentetik proje ayrıca “SYNTHETIC TEST DATA · NOT OFFICIAL” bandı taşır.
