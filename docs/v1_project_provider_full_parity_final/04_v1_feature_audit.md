# V1 feature audit

## A. PROJECT_DATA supported

- Exact 24-unit selector, canonical count, provider-correct terminology, geometry overlay, selector/polygon synchronization, and backend-valued popup.
- Crop catalogue/candidates, S1 readiness, GA/ACO/ABC preview, all three objectives, seed, pinned revision and selection hash.
- Actual analysis creation, immutable run, exact run reload, current crop, recommended crop, optimized and authoritative water, profit, efficiency, feasibility, annual/monthly checks, warnings, crop area/share/HHI, unit result, provenance, and project-only run comparison.
- Existing water/profit charts and the existing monthly-water card receive stored backend series.

## B. PROJECT_DATA not provided by the accepted package/backend

- Current unit/project water, profit, and efficiency baselines.
- Irrigation-method comparison and unit irrigation schedule.
- Project climate/drought time series.

These show `SAĞLANMADI / NOT PROVIDED` with Turkish context; zero or reference values are not fabricated.

## C. Reference-only by scientific design

- Akkaya historical drought/reference indicators and Akkaya benchmark values.
- Canonical 179-parcel reference data and its accepted scientific totals.

These remain available only under `AKKAYA_REFERENCE`.
