# Known limitations

- The accepted package/backend does not supply current-project water, profit, or efficiency baselines. The UI reports them as not provided and does not calculate replacements.
- No compatible project drought/climate time series is supplied. Akkaya drought history remains reference-only.
- Irrigation-method comparison and per-unit irrigation scheduling are not supplied by the project result contract.
- Algorithm comparison becomes graphical only after more than one PROJECT_DATA algorithm/objective run has been stored; a single run gets an explicit explanation and no Akkaya benchmark.
- The known S2 high-budget condition remains `INHERITED_UNCHANGED`.
- This milestone did not push, tag, or deploy.
