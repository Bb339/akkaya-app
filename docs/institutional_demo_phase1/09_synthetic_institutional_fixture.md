# Synthetic institutional fixture

Acceptance tests create `SYNTHETIC_INSTITUTIONAL_TEST_PROJECT` with `not_official=true` semantics and upload all inputs through the public API.

The fixture contains analysis units, crop catalog, current pattern, candidate matrix, scientific resources, six water contracts, verified-like economics, crop-water parameters and phenology. Sources contain `synthetic`/`not_official`, so the run is always labelled `SYNTHETIC / NOT_OFFICIAL` and `SYNTHETIC_TEST_OUTPUT`.

It is not Ministry data, Akkaya official data, field validation or an agronomic reference.
