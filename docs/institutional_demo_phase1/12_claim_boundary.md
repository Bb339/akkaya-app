# Claim boundary

`REFERENCE_MODEL_OUTPUT` demonstrates the accepted frozen reference/project-explicit model and may contain documented legacy assumptions. It is not official or verified institutional evidence.

`SYNTHETIC_TEST_OUTPUT` demonstrates integration behavior only. It is not Ministry data, Akkaya official data, measured water use, real-farm profitability, field validation or external agronomic validation.

`VERIFIED_INSTITUTIONAL_MODEL_OUTPUT` means that selected input contracts passed the repository's authority, year, scope, coverage and confirmation gates. It remains a model output. It is never labelled `FIELD_VALIDATED`.

S2 feasibility continues to come from the frozen engine. Infeasible outputs remain diagnostic; adapters never force feasibility.
