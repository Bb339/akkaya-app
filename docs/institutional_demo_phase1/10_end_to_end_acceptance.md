# End-to-end acceptance

The integration test performs create project → upload → suggested mapping → validation → preview → explicit confirm → readiness → dry-run → scientific execution → stored result → provenance.

Adversarial checks remove or corrupt active water, economics, parameter and phenology evidence and verify that the engine is not invoked. A controlled annual-supply replacement creates version 2, sets `requires_reanalysis`, preserves run A and creates run B with different pinned provenance and water-budget output. A second project remains isolated.

REFERENCE_DEMO regression locks remain covered by the accepted Akkaya tests and an explicit Phase 1 profile/value check.
