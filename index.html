AI-supported Optimum Crop Pattern System

Development of an optimum crop pattern system based on annual water availability in a basin

This login panel presents the thesis decision-support system through an academic, institutional and readable interface. The system opens parcel-level recommendation screens for farmers and basin-scale analysis, comparison and monitoring panels for institutional users.

Prepared by Betül Demir
Advisor Assoc. Prof. Dr. Yeşim Dokuz
Co-advisor Assoc. Prof. Dr. Burak Şen
Farmer panel Own parcels, current crop information, recommended pattern, water saving and income effect.
Institution panel Basin map, scenario comparison, water budget and impact analysis.
Decision outputs Optimum crop pattern, economic effect and feasible recommendations under water constraints.

System access

Sign in with your institution-created account

This prototype uses an institutional pre-registration flow instead of open registration. Farmer accounts are created in the management panel; on first login, users complete their profile before entering their own panel.

Open registration is not enabled in this version Farmer accounts are created one by one by the institution, so username, temporary password, official parcels and permissions can be defined in advance.
1. Institution creates pre-registrationFarmer information, username, temporary password and any mapped parcel records are defined.
2. Farmer signs in for the first timeThe user signs in with the provided credentials and sees the profile completion screen before entering the main panel.
3. Profile completionThe farmer verifies contact details and, if needed, uploads, draws or reviews parcel records.
4. Farmer panel becomes activeAfter setup, the user sees their crop-pattern plan and water/profit comparisons.

Optimization Algorithm

Objective and Plan Mode

Runs backend optimization with the selected parcel, objective mode, and scenario settings.

Note: Scenario 1 treats each parcel primarily as single-crop and ranks the best main recommendation plus strong alternatives. Scenario 2 tests a 1+1 crop / pattern approach; in orchard-perennial parcels, the main crop is preserved and the difference comes from inter-row and irrigation management.

Note: In this version, current total water demand is first divided by total area to calculate the general m³/da value. The default planning quota is the area-based fair quota; equal village share is also shown as a comparison scenario.

The selected objective mode (water efficiency / profit) and plan mode (S1 / S2) work together. The water objective prioritizes using available water more efficiently rather than simply minimizing water; the profit objective prioritizes revenue growth under the water budget.

      Run Count Stability Analysis

      The most suitable run count is selected not only by the highest single result, but by evaluating solution stability, feasibility rate, marginal improvement, and runtime together.

      Because GA, ACO, and ABC are stochastic/heuristic algorithms, they are evaluated through independent repetitions rather than a single run. The default 30 runs are used to calculate average performance and stability indicators. The 50 and 100 run options provide additional stability analysis.
